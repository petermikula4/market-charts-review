# 📊 Market Charts Review

An interactive financial dashboard financial dashboard designed for real-time stock market analysis and charting. This project integrates professional-grade financial tools into a clean, intuitive dark-mode interface.

---

## 🚀 Live Demo
**[https://market-charts-review.netlify.app/]**

---

## ✨ Key Features

*   **Multi-Chart Dashboard:** View multiple stock charts simultaneously using TradingView's advanced charting technology.
*   **Custom Stock Screener:** Filter stocks based on specific criteria such as Market Cap, P/E Ratio, and Technical Ratings.
*   **Dynamic Favorite List:** Manage a curated list of symbols for quick access and comparative review.
*   **Fully Responsive:** Optimized for both large desktop monitors and smaller screens.

---

## 🛠️ Built With

*   **Frontend:** HTML5, CSS3 (Custom Dark Theme), JavaScript, jQuery.
*   **Financial Data:** [TradingView Widgets](https://www.tradingview.com/widget/).
*   **Deployment:** [Netlify](https://www.netlify.com/) with continuous integration from GitHub.
