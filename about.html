About

This page uses Tradingview widgets to display charts of financial instruments. Available categories of financial instruments are: Stock, Funds, Futures, Forex, CFD, Crypto, Indices, Bonds, Economy. Some instruments are not available on this site but only on Tradingview.

It is possible to save settings and groups of symbols from which charts are loaded. This data is stored in the browser in Web Storage and the data remains stored even after the browser is closed.

Settings

You can customize the charts in the settings - you can adjust the charts size (width and height), date range and add indicators. The saved settings will be used for all charts that will be displayed. Charts already displayed on the page will not be affected.

If you have saved the settings but want to insert charts with other settings, choose your settings, mark "use the filled settings", confirm with the OK button and insert the charts.

If a sufficiently small width is specified, the graphs are displayed next to each other and thus it is possible to display several graphs on one screen.

You can display the chart with multiple indicators. You can also add indicators to a chart that is already displayed (from the top menu of the chart), but in this case the number of indicators can be a maximum of 2. It is a limitation of Tradingview for the Basic plan. So if you enter indicators from the settings window, you avoid this limitation and you can display more than 2 indicators.

Charts can be displayed in three ways:

  • by entering a list of symbols in Ticker box
  • by transferring data from the screener to Screener box
  • by loading from saved groups

Ticker box

In the Ticker box, you can directly enter a list of symbols (or tickers in the case of stocks) separated by commas and then display charts by pressing the "show charts" button. You can view information about entering symbols by clicking on the button in the upper right corner of the Ticker box.

Screener box

Screener box allows displaying charts of stocks filtered by screeners together with values ​​from screener columns that will be displayed as labels below the stock charts. In this way, you can get an review of stock charts together with the values ​​displayed in the screener on one screen.

In the stock screener, you can select a default column sets by clicking , add or remove columns by clicking or , sort in ascending or descending order by clicking a column name, or filter data by values ​​by clicking in a column name.

After copying the data into the Screener box and clicking on the "show charts + labels" button, stock charts with labels will be displayed. The label on which sorting was applied will have a blue underline and the labels on which value filters were applied will have blue font.

Clicking on will display the details of the stock and clicking on will display the chart in full screen.

If you want to get the ticker list from the screener, copy the screener data into the Screener box and press the "insert to ticker box" button under the Screener box.

Groups

It is possible to save groups of symbols from which charts can be loaded at once. Groups can be created by clicking on "EDIT GROUPS" in the header of the page.

There is one default group called "Favorites". If a list of symbols is stored in it, after loading the page, the charts of these symbols are automatically loaded at the top of the page under the slider, using the saved settings.

You can create multiple groups. Group charts can be loaded by clicking on the "load group" button under the ticker box.

Symbols info

You can search for the symbol by clicking on "Symbol Search" on any loaded chart.

If only the symbols themselves are entered, the graph of the first symbol will be displayed.

To display a graph of another symbol, enter the source name and a colon before the symbol name, for example MIL:ABT.

Multiple sources can be used and not only stock charts can be displayed, for example AAPL, MIL:ABT, EURUSD, BTCUSDT, SPX500USD display graph of Apple, AbitareIn, EUR/USD, Bitcoin and US SPX 500.

Some symbols are only available on TradingView.
